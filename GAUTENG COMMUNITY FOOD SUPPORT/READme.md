## Project Overview
This project creates a fully styled, responsive website for **Gauteng Community Food Support**, a non-profit organisation that helps people who cannot afford food. **Part 3** builds on Part 2 by adding JavaScript functionality, interactive elements, SEO improvements, form validation, search features, and deployment on a free hosting platform.

---

## Files Included

| File Name | Purpose |
|---|---|
| index.html | Home page — introduction, key services & FAQ accordion |
| about.html | About page — mission, vision, who we are |
| services.html | Services page — all programmes, search filter & seasonal support |
| enquiry.html | Enquiry page — form with JavaScript validation & feedback messages |
| contact.html | Contact page — address, phone, email & Google Maps link |
| css/style.css | External stylesheet — all design and layout rules |
| sitemap.xml | XML sitemap for search engines |
| robots.txt | Instructions for search engine crawlers |

### JavaScript Enhancements
- **FAQ Accordion** — Click questions to expand/collapse answers on Home page
- **Search Functionality** — Filter services instantly by typing keywords
- **Form Validation** — Check user input before submission; validate required fields
- **Dynamic Feedback** — Custom success/error messages shown based on user input and form data

### Search Engine Optimisation (SEO)
- Unique `<title>` and `<meta description>` on every page
- Relevant keywords included in page content
- Proper heading hierarchy (H1, H2, H3)
- Descriptive alt text added to all images
- Clean internal linking between pages
- Mobile-friendly responsive design across all device sizes
- `sitemap.xml` created and submitted
- `robots.txt` created to guide search engine crawlers

### Form Functionality
- **Enquiry Form** — validates name, email format, phone number, subject selection, and message length; displays relevant confirmation messages
- **Contact Page** — Google Maps link, physical address, contact details, opening hours and organisation information

## Technology Used
- **HTML5** — semantic structure on all 5 pages
- **External CSS3** — single linked stylesheet (`css/style.css`)
- **JavaScript** — form validation, search filter, FAQ accordion

- **Responsive Design** — adapts to desktop, tablet, and mobile screens
- **SEO Best Practices** — meta tags, sitemap, robots.txt, alt text, semantic HTML

## How to Open & Test
1. Open this project folder in Visual Studio Code
2. Right-click `index.html` → choose **"Open in Browser"**
3. Click all navigation links to check every page works
4. Test the enquiry form — try submitting empty or invalid information to see validation messages
5. Try searching for a service on the Services page — type keywords to filter results
6. Click FAQ questions on the Home page to expand/collapse answers
7. Resize your browser window to test responsive design on different screen sizes
8. Visit the deployed website at the live link below
